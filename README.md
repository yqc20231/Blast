# PhysX + NvBlast 三维模型破碎爆炸仿真 Demo
## 项目简介
基于 C++ 开发，整合 NVIDIA PhysX 物理引擎 + NvBlast 破碎系统 + OpenGL 实时渲染，实现三维OBJ模型切片碎裂、碰撞断裂、中心爆炸冲击波四散效果；
支持碎片刚体动力学、关节绑定、爆炸冲量施加、随机旋转散落、法线色彩渲染可视化。

## 技术栈
C++17 | OpenGL 3.3 | GLFW + GLEW | glm
NVIDIA PhysX 5.0 | NvBlast 破碎库
OBJ模型解析 | 凸包碰撞生成 | 物理断裂事件回调

## 核心功能
1. OBJ通用三维模型加载、顶点/法线解析
2. 三维网格均匀切片破碎生成碎片区块
3. Blast bond化学键绑定，完整物体受冲击后断裂分离
4. 随机中心点爆炸伤害扩散，距离衰减冲击力+随机自旋
5. 碎片刚体物理模拟、地面碰撞、阻尼运动
6. OpenGL法线着色实时渲染碎裂效果
7. 空格键触发爆炸交互

## 编译运行环境
Windows 10/11 + Visual Studio 2019/2022
依赖库自行配置：
1. PhysX 5.0 SDK
2. NvBlast 完整开发包
3. GLFW、GLEW、glm 图形库
将三维模型 eyeframe.obj 放置程序运行目录即可启动
